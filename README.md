One line, 92 characters: a robot's pickup line that only a machine could say. It lives in the uncanny valley — and the charm is that a human climbed down to meet it there. No diagnostic, no simulation, no cooling fan: the valley is the machine's home, and the punchline is the human coming to it.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt`.
